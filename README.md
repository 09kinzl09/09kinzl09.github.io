# 我们的宇宙

一个纯静态、零依赖、离线可用的小站。**代码是搭好的，内容全部由你填**——照片、日期、时间轴、信、页脚，还有猫狗的名字。

双击 `index.html` 就能打开，不用装任何东西，也不用联网。

## 现在的样子

- **首屏**：开头就是音乐播放器（点一下播放），下面是大标题、两个名字、在一起第几天 / 距纪念日还有几天
- **相册**：按场景分成好几块（日常、旅行、美食、节日……），想加几块都行
- **时间轴**：一条竖向时间线
- **小游戏**：翻牌配对，照片不够 6 张时自动用 emoji
- **一封信**：分段显示，带落款
- **装饰**：左下角是猫（多米），右下角是狗（熊猫），页脚也有一对小的

配色是白 + 天蓝 + 薄荷绿，背景有很淡的爪印。

## 目录结构

```
our-universe/
├─ index.html                 网站（给她看的）
├─ edit.html                  编辑器（给你自己用的）
├─ css/style.css              配色、排版、猫狗颜色
├─ js/config.js               ★ 文字内容 + 相册清单
├─ js/photos-data.js          ★ 照片数据（按相册分组）
├─ js/main.js                 网站逻辑（不用动）
├─ js/editor.js               编辑器逻辑（不用动）
├─ assets/music.mp3           背景音乐
├─ assets/photos/             可选：手写路径时放图的地方
├─ assets/heart.svg           网页图标
├─ scripts/start-tunnel.ps1   可选：推到公网
└─ README.md
```

## 1. 先打开看看

双击 `index.html`。相册、时间轴、信都会显示「还没填」的提示，首屏天数显示 `—`——这是正常的，内容都在等你。

## 2. 填内容：用编辑器（推荐）

1. 双击 **`edit.html`**
2. **基本信息**：标题、两个名字、在一起的第一天、落款、页脚、猫狗名字、音乐文件名
3. **相册**：这里每一行就是页面上的一块照片区。改标题 / 改图标 / 加相册 / 删相册 / 调顺序
4. **照片**：点「添加照片」多选导入，每张下面的下拉框选它属于哪个相册
5. **时间轴**：点「加一条」，日期 + 标题 + 细节
6. **一封信**：直接写，空一行就是一段
7. 右上角点 **导出 config.js** → 弹出代码面板 → 点 **复制全部**
8. 用记事本打开 `js\config.js`，`Ctrl+A` 全选 → 粘贴 → `Ctrl+S` 保存
9. 回到 `index.html` 按 `F5`

照片那份同理：点 **导出 photos-data.js** → 复制 → 粘进 `js\photos-data.js`。

> 为什么是"复制粘贴"而不是直接保存？因为本地打开的 HTML 文件（`file://`）里，浏览器的保存框和自动下载经常被拦掉。复制粘贴这条路一定有效。

编辑器每次打开都会读当前的两个数据文件回填，随时回来接着改。

## 3. 相册怎么规划

默认给了 5 个：我们的瞬间 / 日常碎片 / 一起旅行 / 美食地图 / 节日纪念。

想改成自己的（比如「熊猫的日常」「多米的丑照」「毕业」「第一次一起过年」），直接在编辑器里改标题、点「加一个相册」。**页面上有几块照片区，完全由这份清单决定**，不想要哪块删掉就行。

## 4. 照片

- 编辑器导入的图会**缩到 1400px、转 JPEG、内嵌**进 `js/photos-data.js`，所以不用自己拷图文件
- 也可以手动：图片放 `assets/photos/`，在 `config.js` 的 `photos` 里写 `{ src: "assets/photos/a.jpg", caption: "说明", album: "daily" }`
- HEIC 不行（浏览器解不了），导入前先在电脑上转成 JPG

体积参考：每张 1400px 的 JPEG 约 150–350KB，转 base64 后多三分之一。20 张大概 4–6MB，打开不慢。

## 5. 音乐

`assets/music.mp3` 就是现在的背景音乐（梁静茹《情歌》，191kbps，5.95MB）。

- 换歌：用同名文件覆盖 `assets/music.mp3`，配置不用动
- 或者放新文件，在编辑器「背景音乐文件名」改成 `assets/新文件.mp3`
- 留空就不显示播放器

**浏览器不允许自动播放**，所以必须点一下播放按钮——这个改不了，所有网站都一样。

## 6. 猫狗的画

现在左下角是猫（多米，按你给的照片做的：白底、灰色虎斑头、琥珀色眼睛），右下角是狗（熊猫，黑白配色，等你补充照片后再调）。

想改颜色，打开 `css/style.css` 顶部的这几个变量：

```css
--cat-body: #ffffff;    /* 猫身体 */
--cat-grey: #97a3ae;    /* 猫的灰斑 */
--cat-eye:  #e0a13c;    /* 猫眼睛 */
--dog-body: #faf7f2;    /* 狗身体 */
--dog-dark: #2e3640;    /* 狗的黑斑 */
```

造型本身在 `index.html` 顶部的 `<symbol id="pet-cat">` / `<symbol id="pet-dog">` 里，想改形状就在那改。

## 7. 拷进 U 盘

整个 `our-universe` 文件夹原样复制到 U 盘，双击里面的 `index.html` 就能看。照片、样式、游戏、音乐全在本地，几十年后只要能打开 HTML 的设备就还在。

> 要求：文件夹结构别打散，`index.html` 必须和 `js/`、`css/`、`assets/` 在同一层。

## 8. 推到公网（可选）

需要本地静态服务器 + `cloudflared`，这套流程**没在本机验证过**：

```powershell
cd C:\path\to\our-universe
python -m http.server 8080

# 另开一个终端
cloudflared tunnel --url http://localhost:8080
```

会打印一个 `https://xxx.trycloudflare.com`，发给对方即可。注意地址是临时的、关窗口就失效，而且运行期间这个文件夹是公开可访问的。

也可以直接跑 `scripts/start-tunnel.ps1`。

## 9. 已知限制

- 相册里的照片是「按 id 分组」的，改相册 id 会让已导入的照片失联（改标题没事）
- 没有后端，所以没有留言板 / 点赞 / 访客统计
- 翻牌游戏需要至少 6 张照片才用照片，否则用 emoji
- 视频区块还没做，想放视频说一声
